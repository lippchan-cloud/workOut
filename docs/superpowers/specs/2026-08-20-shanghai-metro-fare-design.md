# 上海地铁调价对照页 — 设计说明

日期：2026-08-20  
状态：待实现

## 背景与目标

根据公开「现行票价及两个方案不同乘距票价」表，提供一个**独立静态页面**：用户按线路选择起点、终点后，看到估算乘距，以及**现状 / 方案一 / 方案二**三档票价对比。

不接入 workOut 登录、AppShell、后端 API。

## 已确认决策

| 项 | 选择 |
| --- | --- |
| 交付形态 | 独立静态 HTML（浏览器直接打开或静态托管） |
| 路径范围 | 主网全网可换乘，按最短乘距估票价 |
| 线路覆盖 | 上海地铁主网常规线（约 1–18 号线等），不含磁浮、金山等 |
| 实现路径 | 纯前端 + 内嵌站点图 + 本地 Dijkstra + 固化票价表 |

## 整体结构

- **路径**：`static/metro-fare/index.html`（及相关资源同目录）
- **组成**：
  - `index.html`：页面结构与样式
  - `network.json`（或等价）：站点、线路、邻接区间公里、换乘连通
  - `app.js`：选站 UI、最短路、票价查表、结果渲染
- **与 workOut**：业务隔离；不改 React 路由、鉴权、Spring 接口。可选在 README 加一行入口说明，非必须。

## 交互与结果展示

### 选站

- 起点、终点各自：**先选线路 → 再选该线车站**。
- 车站列表支持关键字过滤。
- 起终点可跨线；换乘由最短路自动处理。

### 计算时机

- 起点与终点均有效且不相同时，**即时计算**并刷新结果。
- 可保留「计算」按钮作为兜底（例如数据异步加载完成前禁用）。

### 结果区

- 估算乘距（公里，保留合理小数位，如 1 位）。
- 三列票价：**现状 / 方案一 / 方案二**（元，整数）。
- 相对现状的涨幅（`+X 元`；不变则显示 `+0` 或「不变」）。
- 简要路径摘要（线路段与换乘站，例如：`1号线 莘庄→人民广场 → 换2号线 → 静安寺→张江高科`）。
- 固定说明：乘距为估算，仅供对照调价表，**非官方计费结果**。

## 数据与算价规则

### 路网

- 节点：车站以站名归一为唯一节点；换乘站不拆成多节点，天然连通各线。
- 边：同线相邻站区间，权重为公里数（正数）。
- 数据来源：公开可复用的主网站点/区间数据，整理后内嵌；实现时在文件头或 README 记录出处与日期。

### 算法

- 以公里为边权的 Dijkstra，求起终点最短乘距及一条对应路径。
- 换乘不额外加价、不加公里（零换乘惩罚），仅通过「同站多线」连通影响路径。

### 票价表

按调价图固化三段查价函数（公里落入半开或按表约定的区间规则，实现时与图一致并单测覆盖边界）：

**现状（摘要规则，实现以完整分段表为准）**

- 0–6 km：3；之后约每 10 km 加 1 元（与图中合并单元格一致），直至表内最高档。

**方案一 / 方案二**

- 按图中各乘距档对应金额实现完整分段查找；不以摘要近似替代边界档。

实现文件中应包含与图一致的完整 `[{minKm, maxKm, current, scheme1, scheme2}, ...]`（或等价结构），并注明「右端开/闭」规则。

### 边界与错误

| 情况 | 行为 |
| --- | --- |
| 起终点相同 | 提示重选，不展示票价 |
| 图中不可达 | 明确「不可达」提示 |
| 乘距超出表内最大档 | 标明「表外」或按设计采用最高档，并在 UI 说明；推荐：**标明表外、仍显示最高档对照并加注** |
| 未选齐 | 结果区为空或占位文案 |

### 误差声明

公开区间公里可能与官方运营里程不一致；页面始终展示「估算」说明。

## 非目标（本版不做）

- 磁浮、金山、市域铁路特殊票价
- 优惠卡、日票、出站换乘时限等业务规则
- 后端服务、登录、与 workOut 业务数据打通
- 实时官方票价 API

## 验收标准

1. 用浏览器打开 `static/metro-fare/index.html`（或本地静态服务）可完整使用。
2. 可选不同线路起终点（含跨线换乘），得到乘距与三档票价。
3. 同站、不可达有明确提示。
4. 票价查表与调价图抽样点一致（至少覆盖短途、中途、长途及档位边界各若干例）。
5. 页面有估算免责说明。

## 测试建议

- 对票价查表函数做纯函数单测或同页可运行的断言样例（边界公里）。
- 对 Dijkstra 用小型人工图做可达/最短路断言（可选；主网全量以手工抽样验证）。
