# workOut
记录每日训练内容
## 核心功能：
1. 导航栏第一个，用户可以记录，当日消耗项和当日摄入项。
2. 当日消耗项，是一个输入框，可以记录一条内容，记录日期默认是操作时间，也可以自己更换
3. 当日摄入项，是一个输入框，可以记录一条内容，记录日期默认是操作时间，也可以自己更换
4. 导航栏，第二个，是一个日历，按周显示，默认选中今日
5. 选中日期后，下面有列表，按照时间正序展示，消耗绿色，摄入红色。也可以按日期导出一个csv文件，
6. 我的信息页，可以填充个人基本信息，身高体重。
